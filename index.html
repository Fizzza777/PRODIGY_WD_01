About The Project

💧 The Problem

The Water Jug Problem involves measuring a specific quantity of water using two jugs with fixed capacities. How can you reach the exact target using only Fill, Empty, and Pour operations?

🧠 The Algorithm

We use an AI search technique called Breadth-First Search (BFS). BFS systematically explores the state space level by level, which guarantees finding the shortest possible sequence of steps (the optimal path).

🌐 State Space

Each state is (Jug A, Jug B). The AI builds a graph of valid moves and uses a queue and a 'visited set' to avoid infinite loops and find the goal efficiently.
